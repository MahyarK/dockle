# Dockle icon

`Dockle.png` is the original artwork. `Dockle.icns` contains standard macOS icon sizes and is copied into the app by `build.sh`.

Created using the built-in image generation tool.

## Generation prompt

Use case: logo-brand. Create one finished bespoke macOS app icon for Dockle, a utility that shows floating live window previews above the Dock. Square 1024x1024 PNG with genuine transparent outside corners. Single large macOS rounded-square tile, centered, filling 88% of canvas, straight-on view. Sleek midnight graphite ceramic tile with restrained satin finish and refined rounded bevel. Central bold sculptural emblem: two overlapping rounded rectangular preview windows hovering above a short polished dock pedestal; front window pearlescent frosted silver with subtle cool blue transmitted light, rear window smoky blue glass offset slightly up and right. A tiny dark rounded square inset at center of the dock pedestal aligns with the floating preview, conveying one app opening a larger view. Distinctive carefully proportioned silhouette, generous negative space, crisp thick contours legible at 32 pixels, refined tactile depth with soft studio highlights. Front preview contains only one subtly inset dark horizontal title-bar line, otherwise blank. Premium understated desktop utility identity, optically balanced. No letters, no text, no cursor, no magnifier, no eye, no extra decorative objects, no neon, no sparkles, no scenery, no presentation board. Deliver the actual icon asset alone, not a mockup.
